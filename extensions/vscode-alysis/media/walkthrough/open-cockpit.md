# Open Alysis Code

The Alysis Code sidebar is the main conversation. Ask a question or describe an outcome in the box at
the bottom. Replies, progress, approvals, and errors stay together in that one place.

Plans, diffs, artifacts, and diagnostics open as focused details on the right only when you need
them. They do not create a second chat input.

Forge **Execute Plan** is review-only: it writes only to your working tree and never commits or
merges. Anything the installed CLI cannot support stays disabled with a clear reason.
