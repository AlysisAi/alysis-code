## Kilo Code / OpenCode — MIT

Alysis Code's shared sidebar adapts layout and styling from Kilo Code:
https://github.com/Kilo-Org/kilocode/tree/28bc6b0e06cca3a02c280a2ba060f50d69a5e6e7/packages/kilo-vscode/webview-ui/src

Source files: styles/chat-layout.css, styles/prompt-input.css,
styles/prompt-dropdowns.css, styles/permission-dock.css, styles/history.css,
styles/welcome.css, and their chat components.

The adapted files are startView.css, startView.html and startView.js. Changes
include Alysis branding, dependency-free DOM rendering, host message dispatch,
personas, explicit permission modes, context tools, Forge navigation, and
